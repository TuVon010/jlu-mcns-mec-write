## 没有原样固化的意见

以下是对材料的审校判断，不是假称原作者已经明确这些限制。

| 历史建议或示例 | 本 skill 的处理 |
| --- | --- |
| 三个挑战、四项贡献、每段三篇、系统参数最多两项 | 只作组织范例；数量服从真实贡献与证据 |
| Offloading Model 不独立、指标不写公式、不用 P1 | 检查是否重复与是否需要独立定义；按内容和模板决定 |
| Random 是 bound、MINLP 可直接推出 NP-hard | 不采纳；分别要求数学关系或复杂性论证 |
| 传统优化不能实时、固定算法名单就是 SOTA | 限定规模、信息、硬件、预算和可比性；需要真实证据 |
| 所有变量都进入 actor、算法一律放进 DRL 框架 | 不采纳；允许学习、确定性求解和修复分工，要求完整映射 |
| 避开最相似工作、用年龄/出版模式筛除文献、分散组内引用 | 不采纳；按相关性与证据组织，正面说明最接近工作的差异 |
| 为降重换技术名词、分号能判 AI、禁所有代词或分词 | 不采纳；保留准确术语，按可读性和指代是否清晰修改 |
| deadline/能耗/衰落“必须补上” | 核对是否为真实场景必要假设；研究设计变化须同步模型、实现和实验 |
| 图中省略 average、固定图形长宽/字体/图例顺序 | 仅在统计含义明确、可读且符合投稿模板时采用 |

M2 末尾的 QNE 名称与推导不完整；转写还存在技术名词误识别。它们只作查证线索，不据此生成公式、全称、最优性或收敛结论。

## 后续吸收新材料

新增规则至少说明“触发情境→采取的动作→如何判断完成→适用前提”，再放入现有对应章节；同义规则合并。仅在会改变决策时新增条目，不把每次反馈堆成永久禁令。改变已有结论时更新案例版本与证据范围；只需公开提炼规则和必要出处，不默认分发原始内部材料。
