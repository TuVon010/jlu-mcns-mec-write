# 版本、证据与方法迭代

用于“按旧批注改新稿”“方法已更新”“稿件、代码和结果不一致”及从历史材料沉淀规则。普通单句润色无需建立完整台账。

## 1. 先确定当前对象，再使用材料

记录用户指定的稿件/分支/方法版本，以及实际可访问的代码、配置、结果、评审批注和参考论文。文件日期仅是线索，不自动代表用户认可的新版本；以用户指明的对象为起点。未指明时先检查目录、内容和依赖，确实存在多份无法辨别的有效稿才询问。

| 材料 | 可支持什么 | 不能直接推出什么 |
| --- | --- | --- |
| 当前作者说明与稿件 | 拟采用的研究设定及表述 | 实现已经正确、实验已完成 |
| 代码与配置 | 实际实现及运行条件 | 理论正确、实验结果属于该版本 |
| 日志/数据/图表 | 特定运行与统计支持的结果 | 任意新版本仍保持同等性能 |
| 旧批注与会议 | 当时的问题、审查线索与写作偏好 | 当前仍存在相同错误或模块 |
| 参考论文/写作笔记 | 结构、叙述方法与可核查先行研究 | 当前系统采用相同假设、节点或公式 |

冲突时并列列出“稿件称什么—实现/结果显示什么—影响哪些主张”，不以代码总是优先或最新文件总是正确来消除冲突。能从现有证据解决的直接修；涉及真实研究设计取舍的标【待确认】，不静默改变系统或编造结果。

## 2. 将旧批注转成当前可验证动作

旧行号只用于回溯，按章节功能、公式标签、术语和语义在新稿重新定位。建议使用：

`来源/旧编号 | 原问题本质 | 适用前提 | 当前证据位置 | 当前适用性 | 修订状态 | 修订动作/不适用原因`

适用性统一为：**仍适用 / 已解决 / 机制已更换 / 仅属风格偏好 / 证据不足**；修订状态为：**未处理 / 待作者确认 / 已修待验证 / 已验证 / 不适用（附理由）**。有条件成立的意见在“适用前提”栏说明。没有发现旧方法不等于当前正确；原问题也可能以新形式继续存在。例如去掉聚类后，“模块输入输出不清”仍可能适用，但“先聚类再学习”已经不适用。

将资料中的意见分成三类：

- **可复用原则**：角色清楚、依赖闭合、主张有证据、术语及变量一致。
- **条件建议**：某种章节顺序、公式先总后分、某模型单独成节；按实际内容和模板决定。
- **历史个案/待查观点**：具体节点只负责控制、某算法必须包含几类动作、旧消融与性能数值。仅在当前证据支持时使用。

组内偏好如少用分号、特定基线顺序、参考文献数量不能变成硬性科学规则；不据此推断 AI 写作、为查重随意替换技术术语或隐去最接近的先行工作。

## 3. 方法变更后做有边界的跨章同步

先写一行“旧机制 → 新机制 → 为何更改 → 已有证据/缺口”，再沿实际依赖复核：

| 变更 | 同步位置 |
| --- | --- |
| 节点角色、链路或任务执行路径 | 系统图、Overview、模型假设、成本及约束、实验配置 |
| 决策/动作/求解分工 | 问题变量、MDP/POMG、输入输出、伪代码、框图、复杂度 |
| 奖励、权重或可行性处理 | 原目标、奖励解释、实际执行、指标定义、失败/回退统计 |
| 网络组件或训练方法 | 方法动机、损失与更新、训练/推理差别、基线、消融与开销 |
| 实验版本或统计方式 | 参数表、图数据、图题、结果段、摘要/贡献/结论数值 |

对涉及结论的实验至少核对方法版本、关键配置、数据/运行来源与统计口径。若旧结果未覆盖新方法，将结论标为待重测或缩小表述；不能自动把旧图换上新算法名。没有改动依赖的章节无需为了“全篇同步”重写。

### 含优先级/紧急度机制时的证据闭环

这是适用时启用的审查扩展，不是两场会议给出的实验结论：

1. 定义优先级来自什么，在哪个目标、约束、动作或调度模块发挥作用。
2. 查明权重提高是否改变总成本的定义；不同权重下的聚合成本不能未经统一评价就直接比较优劣。
3. 若主张优先保障紧急任务，应查看按优先级分组的完成率、deadline 满足情况、时延或失效率等相符证据；总平均值改善不能单独证明该主张。
4. 有条件时用取消优先级/统一权重等公平消融区分机制作用，同时说明其他任务的代价。没有相应结果就列证据缺口，不填写虚构指标、数值或收益。

## 4. 优先级按影响定，按证据验收

- **P0**：改变科学含义或结果有效性的矛盾，如目标与执行不一致、单位造成错误、子问题最优被称整体最优、版本不匹配的实验结论。
- **P1**：妨碍判断方法和证据的缺口，如模块关系未解释、重要条件未定义、消融无法归因。
- **P2**：不改变技术含义的措辞、大小写与排版。若术语混用实际指不同对象，应提高级别。

交付时列当前已修且已验证、已修待验证、证据不足及不适用旧意见的原因。不能因旧批注被逐项勾选，就宣称新算法或全文已通过数学与实验验证。
